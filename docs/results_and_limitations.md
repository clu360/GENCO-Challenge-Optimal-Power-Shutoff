# Results And Limitations

Three GENCO final checkpoints have complete 301-topology searches and designated
Reference A/B audits. Fine-tuning did not establish a below-baseline exact AC risk
benefit on this single exploratory Texas case: normalized Reference A risks are
1.164144 (G500), 1.089042 (Grid-to-Random), 1.089060 (Grid-to-Wildfire). The latter
two select the same outage pair but different service decisions. All comparisons
must retain that selected decision and audit role, not treat A as the native
wildfire-aware solution. Native and exact values are separate table columns.

Seven of eight Phase I fits are certified. Native G500 has saved epochs but is
not yet certified; the native final OPS/reference branches are pending. Pending
is not a zero value or a scientific failure. These outputs will be incorporated
through later, separately verified commits. Phase I is not declared complete.

The official GOC-500 sample supports a bounded new numerical demonstration. It
does not establish reproduction of the historical held-out population. Stage J
physical evaluation rows and search evidence are retained as separate studies.
The current release does not supply a cross-grid aggregate model ranking.

Data conditioning, replacements and numerical failures are preserved in the
private scientific archive. Original training/validation labels were accepted
under the frozen electrical gates; feasibility-conditioned sampling limits
population generalization. Full-history archives, cluster account data and raw
Texas inputs with unresolved redistribution rights are not public payloads.

No global optimality, causal architecture advantage, measured cross-hardware
speedup or actual challenge submission is claimed. Full recomputation and optional
AC execution must not be confused with results-only regeneration.
